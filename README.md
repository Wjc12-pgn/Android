# Android 备忘录App
这是一个基于Android Studio开发的备忘录应用课程设计项目，使用Java语言开发。

## ✨ 功能介绍
- 新增备忘录笔记
- 查看、编辑、删除备忘录
- 备忘录关键词搜索
- 标记重要备忘录

## 🛠️ 开发环境
- 开发工具：Android Studio
- 开发语言：Java
- 数据库：SQLite（本地存储）

## 📦 仓库地址
https://github.com/Wjc12-pgn/Android

## 📝 使用说明
1. 下载项目源码，使用Android Studio打开
2. 等待Gradle同步完成
3. 连接真机或者启动模拟器，运行App
